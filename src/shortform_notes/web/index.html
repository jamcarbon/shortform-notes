Where should the summary run?

shortform-notes turns an Instagram Reel, TikTok, or YouTube Short into a Markdown note with the caption, transcript, and takeaways. One model call per reel writes the summary. Choose where that call runs.

Stored in the local config file and sent only to api.openai.com. Get one at platform.openai.com under API keys.
Stored in the local config file. Get one at console.anthropic.com under API keys.

How should audio be transcribed?

The transcript is what makes spoken-only reels useful. It is optional. Caption-only notes still work.

Transcription runs on OpenAI's audio model. The key is stored in the local config file.

On-screen text (optional)

Many recipe and tip videos put the details in text overlays rather than speech. Turning this on downloads the full video, samples frames, and reads the text in them. It is slower, and on a paid backend it costs extra per frame. Off by default.

Left empty, frames are read at the video's cuts, which is usually what you want. Fill it in to read on a clock instead: 1 catches overlays that stay on screen, 0 reads every frame (about 30 times the frames and cost). Identical consecutive frames are skipped before any paid call.

Where should notes be saved?

One .md file per reel, named <date>-<creator>-<title>.md. Any folder works. For Obsidian, use a folder inside the vault.
